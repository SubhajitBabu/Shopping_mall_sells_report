Shopping Mall Sales Analysis
Project Overview

Shopping Mall Sales Analysis is an end-to-end data analytics project developed using PostgreSQL, Google Sheets, and Power BI to analyze retail sales performance, customer behavior, product categories, payment methods, shopping malls, and purchasing patterns.

The project starts with data cleaning and preparation in Google Sheets, followed by data validation and SQL-based analysis in PostgreSQL. The processed data is then connected to Power BI to build an interactive dashboard containing key performance indicators, charts, filters, and detailed analytical tables.

The dashboard provides a consolidated view of sales performance and helps identify important trends across categories, shopping malls, gender, age groups, payment methods, quantity, transactions, and sales over time.

Project Objectives

The main objectives of this project are:

Analyze overall shopping mall sales performance.
Calculate important business KPIs such as Total Sales, Transactions, Customers, Quantity, and AOV.
Analyze sales performance across different product categories.
Compare sales generated by different shopping malls.
Understand customer purchasing behavior by gender and age group.
Analyze the distribution of payment methods.
Identify monthly sales trends.
Compare quantity, sales, and AOV across categories and shopping malls.
Create an interactive Power BI dashboard for business reporting.
Use PostgreSQL to perform structured SQL-based data analysis.
Use Google Sheets for initial data cleaning, validation, and preparation.

KPI calculations
Example: Total Sales
SELECT 
    SUM(quantity * price) AS total_sales
FROM shopping_mall;
Example: Total Transactions
SELECT 
    COUNT(DISTINCT invoice_no) AS total_transactions
FROM shopping_mall;
Example: Total Customers
SELECT 
    COUNT(DISTINCT customer_id) AS total_customers
FROM shopping_mall;
Example: Total Quantity
SELECT 
    SUM(quantity) AS total_quantity
FROM shopping_mall;
Example: Average Order Value
SELECT 
    SUM(quantity * price) / COUNT(DISTINCT invoice_no) AS average_order_value
FROM shopping_mall;
